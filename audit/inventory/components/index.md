# Component inventory — index (Phase 2)

Per-screen component catalogs live alongside this file as `<screen-id>.json`,
matching the IDs in `audit/inventory/sitemap.json`. Shared header/sidebar
controls that repeat on every authenticated screen are factored out into
`_shared-chrome.json` rather than duplicated in each screen file.

| File | Screen |
|---|---|
| `_shared-chrome.json` | Header + sidebar chrome shared by every authenticated screen |
| `login.json` | Iniciar Sesión (Login) |
| `nueva-cuenta.json` | Registro de Nuevos Clientes |
| `mi-cuenta.json` | Mi Cuenta (Datos Personales / Dependientes / Direccion tabs) |
| `estado-cuenta.json` | Estados de Cuenta (Cuenta por Pagar) |
| `rastreo.json` | Rastreo de Paquetes (incl. Movimientos modal, Histórico modal, Adjuntos dialog, row detail expander) |
| `prueba-exportacion.json` | Prueba de Exportación |
| `prealerta.json` | PreAlerta |
| `pago-online.json` | Pagos Online (incl. hidden checkout sub-form found via static DOM inspection) |

Each file uses the schema:
```json
{
  "screenId": "...",
  "screenName": "...",
  "url": "...",
  "sharedChrome": "pointer note",
  "components": [ { "type": "...", "name": "...", "action": "..." } ],
  "subViews": [ { "id": "...", "name": "...", "components": [...] } ],
  "notes": [ "..." ]
}
```
`type` is one of: button, dropdown, text field, email field, phone field,
number field, date field, password field, select, checkbox, file upload,
table, filter, modal, breadcrumb/tabs, pagination, status message.

Raw and condensed DOM dumps this inventory was built from live under
`audit/inventory/raw/` and `audit/inventory/condensed/` (generated by
`audit/scripts/dump-inventory.ts` + `audit/scripts/condense-raw.ts`, using
`audit/support/inventory.ts`) for traceability.
